帮助与支持

本页适用于《逆风开局·锋芒》1.2.0。游戏人物、公司、收入和市场均为虚构。

怎样开始

  1. 新开局后选择名字、角色身份、感情偏好、行业与天赋。角色名字可以使用昵称，无须填写真实姓名。
  2. 每天有三次行动。交付、研发、走访、推广与休息各有成本和效果；只有选择“结束今天”才进入当天结算。
  3. 第2天在旧工坊选择成长方法。前往“锋芒”页查看练习条件，满足后主动试练。
  4. 第10、20、30天参加公开展示。展示失利也可以继续经营。完成三十天后，查看事业结果与关系尾声。

进度和存档

进度自动保存在当前设备。设置中可导出 JSON 存档、载入同版本存档、恢复上一局。新开局或导入替换前会保留当前局；备份失败时会停止替换。建议在更换设备或清理存储前先导出。

锋芒版使用独立存档。原版、同行版的存档请在对应版本继续；本版不自动转换旧版进度。导出的文件由你选择保存位置，游戏不会自动把它上传给开发者。

常见问题

为什么不能继续行动？先完成正在显示的剧情选择，或检查剩余行动、精力和现金。尚未达到的条件会在对应按钮旁显示。

为什么方法还没升级？达到天数和经营条件后，还需要执行一次试练。工法路线在品质满级时，可用“工法复检”补齐练习次数。

不想展开恋爱怎么办？开局选择“只做朋友”，或在剧情中明确友情、距离和告别。友情与独处都有尾声。

删除应用后进度还在吗？系统清理方式会影响本地数据。不要依赖卸载恢复进度，也不要把卸载视为所有平台上都彻底清除数据；请先导出需要保留的存档。

反馈问题

通过下方项目工单入口联系维护者，标题注明“逆风开局·锋芒”。建议提供应用版本、设备和系统版本、游戏第几天、操作步骤及错误提示。

打开支持工单

工单公开可见，提交需使用 GitHub 账号。不要填写密码、支付信息、真实联系方式或其他敏感资料；不要直接公开完整存档。若截图包含个人信息，请先遮盖。游戏本身无需 GitHub 账号。

隐私政策

更新日期：2026年10月26日 · 适用版本：1.2.0

1. 游戏内如何处理信息

本游戏是离线单人游戏，无需注册账号。开发者没有在游戏内设置收集或上传个人信息、使用行为、设备标识、位置、通讯录、照片、相机或麦克风数据的功能，也没有接入广告、追踪或分析 SDK。游戏内没有在线聊天、用户社区、内购或在线 AI 生成。

2. 设备上的保存内容

为了继续游戏，应用会在本机保存角色昵称、身份与感情偏好、经营数值、剧情选择、进度、结局和成就记录、声音偏好，以及上一局备份。无法读取的存档可能作为原始数据保留，便于你自行导出排查。姓名和偏好用于塑造虚构角色，不要求对应你的真实身份或生活。

这些内容存放在应用本地存储中；Apple 平台版本还使用本应用的本地偏好存储保存镜像。应用不会自动将这些存档发送给开发者。系统级备份由你的设备与系统设置决定。

3. 由你主动导入或导出

导入仅读取你选择的存档文件；导出仅生成你主动选择保存的文件。若你选择云盘或把文件分享给他人，后续处理受相应服务和接收方约定约束。导出文件可能包含角色昵称、身份、感情偏好和剧情记录，请选择可信的保存与分享位置。

4. 保存期限与删除

本机存档用于持续保存进度，没有自动到期时间。重新开局会保留上一局备份及结局收集记录，不是彻底删除全部数据。你可以通过系统的应用数据管理清理本地数据；iPhone/iPad 上“卸载 App”与“删除 App”对数据的处理不同。Mac 移除应用后，应用数据可能仍保留。需要对应版本的清理步骤，可通过本页支持入口联系维护者。

已经导出的文件、云盘副本和系统备份需要分别管理。开发者不能远程读取或替你删除设备上的存档。

5. 支持网站、工单和平台服务

本支持页托管于 GitHub Pages，工单使用 GitHub Issues。访问网站或主动提交工单时，GitHub 会根据其隐私声明处理请求及你提交的信息；这与离线游戏内的本地存档不同。本页没有额外加入统计脚本或表单。公开工单中的账号名、文字和附件可被维护者及其他访问者看到。

App Store 的下载、购买与系统诊断由 Apple 依据其服务和你的设置处理，游戏不会取得你的支付卡信息。可查看Apple 隐私政策。

6. 儿童和内容

本作包含虚构创业压力、职业伦理选择和成年人之间可选的恋爱或友情，不以儿童为专门受众。游戏不要求真实年龄或真实身份，也不主动收集儿童个人信息。具体年龄适宜性以商店分级及家长判断为准。

7. 联系与变更

隐私疑问可通过支持工单入口联系本项目维护者。公开工单中请只描述问题，不提交敏感个人资料。若未来版本改变数据处理方式，本页会更新日期与说明，并按适用要求提供必要提示。
